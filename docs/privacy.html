Privacy

The short version: there are no accounts, and nothing you do here is tied to you. The S&Poké 500 is a free, independent, non-commercial fan project — a static web page and an iPhone app that both read the same public price files. There is no user database, because there are no users to put in one.

The iPhone app

  • No accounts, no sign-in, no tracking. The app contains no analytics SDK, no advertising identifier and no crash-reporting service. Its App Store privacy label is “Data Not Collected.”
  • Your watchlist and the quantities you own stay on your device, in one small file inside the app's own storage. They are never uploaded anywhere, and deleting the app deletes them.
  • What the app asks the network for is the same public data this site serves — the daily index files under poke500.com/data/ — plus card thumbnails from TCGplayer's image CDN. TCGplayer, as the host of those images, sees the ordinary request information any web server sees. Settings → Card images turns image requests off entirely, after which the app requests nothing but the price files.
  • Outbound links (TCGplayer, PriceCharting, eBay, the newsletter, this site) open in Safari. Once you are on someone else's site, their privacy policy applies, not this one.

This website

  • No cookies and no consent banner. Anonymous, aggregate visit counts are measured with GoatCounter, which is cookieless and stores no personal data.
  • Your settings stay in your browser. The theme, the card-images toggle and whether you dismissed the banner live in localStorage on your own machine and are never sent anywhere.
  • The site is a static page hosted on GitHub Pages; like any web host, GitHub processes request data in order to serve it.

The email newsletter

If — and only if — you subscribe, your email address is stored by Buttondown, the service that sends the weekly recap. It is used for that one thing: sending you the recap. It is never sold, rented or shared, and every email carries a one-click unsubscribe that takes effect immediately. Subscribing is double opt-in, so nobody can add your address but you.

Children

This is a price reference, not a service that collects anything. It asks for no personal information from anyone, including children.

Changes and contact

If this policy changes, the new version replaces this page and the date below moves. Questions, or something here that looks wrong? Open an issue on the GitHub repository — that is the project's only contact channel, and it is public.
